# Shell completion

`fermut completions <SHELL>` prints a shell completion script to
stdout. Redirect to the right location for your shell.

Supported shells:

- **[bash](bash.md)**
- **[zsh](zsh.md)**
- **[fish](fish.md)**
- **[powershell](powershell.md)**
- **[elvish](elvish.md)**

## Updating

The completion scripts encode the current flag set. Regenerate
after upgrading fermut to pick up new flags / subcommands.
