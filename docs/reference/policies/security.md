# Security

Reporting channel, response timeline, and scope live in the
repository's [`SECURITY.md`](https://github.com/KovantAI/fermut/blob/main/SECURITY.md).
Keep that file as the single source of truth so the GitHub security
advisory UI and this documentation site never disagree.

Short version:

- Report privately to <security@kovant.com> with subject prefix
  `[fermut security]`.
- Do **not** open a public GitHub issue for security problems.
- Acknowledgement target: 3 business days. Patch availability or
  status update target: 30 days. Coordinated public disclosure
  target: 90 days. See `SECURITY.md` for the full timeline table.
- fermut is pre-1.0; only the latest `0.x` release receives security
  fixes. Older versions are end-of-life the day the next release
  ships.
